Global rules: ~/.claude/CLAUDE.md. Root rules: ../CLAUDE.md. This file holds what is specific to this project.

## What this is

SIGNAL, a marketing ops dashboard and analytics setup, built as a proof-of-work
portfolio piece for Amrudin Catic (marketing engineer, amrudincatic.com).
It shows full-funnel marketing operations (spend, leads, CPL, ROAS, channel
mix, funnel stages, organic/SEO) alongside a documented analytics tracking
plan, so a prospective client or employer can judge the quality of work in
this space. It is a focused demo, not a product: keep it small (YAGNI).

## Status

Finished and live at https://amrudincatic.github.io/marketing-ops-dashboard/.
The repo `amrudincatic/marketing-ops-dashboard` is public, so everything
committed here is public.

- `src/App.jsx` composes the page from `src/components/`: header with filters,
  KPI row, funnel, trend chart, ROAS by channel, spend mix, sortable table, footer.
- Data: `src/data/mockData.json`, generated by `scripts/generate-data.mjs`
  (seeded, 90 days, five channels in `src/data/constants.js`), read through
  `src/data/dataService.js`. The math lives in `src/data/metrics.js`.
- A test fails when `mockData.json` drifts from the generator: run
  `npm run gen:data` after changing the generator.
- Analytics docs in `docs/analytics/`. `metric-definitions.md` must match
  `src/data/metrics.js` (the README promises it); change both together.
- Tests: Vitest and React Testing Library in `src/test/`.

## Confirmed decisions

- Focus: full-funnel marketing ops overview
- Scope: dashboard UI plus an analytics tracking plan (documentation)
- Stack: React + Vite + Recharts, plain CSS with design tokens in
  `src/styles/tokens.css`
- Aesthetic: 80s synthwave (neon magenta and cyan on deep purple, grid horizon,
  glow)
- Shape: single-page command center (Approach A) with interactive filters that
  recompute the numbers client-side
- Data: a realistic mock dataset served through a small data-layer module so it
  reads like it is fetching from an API
- Deploy: GitHub Pages via GitHub Actions (live link, not just a repo)

## Run, test, deploy

- `npm install`, then `npm run dev`. `npm test` runs the tests, `npm run build`
  builds `dist/`.
- `vite.config.js` sets `base` to `/marketing-ops-dashboard/` (override with
  `VITE_BASE`).
- Every push to `main` runs `.github/workflows/deploy.yml`: `npm test`,
  `npm run build`, then publishes `dist/` to GitHub Pages (production).
